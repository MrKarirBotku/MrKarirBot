# Roadmap MrKarir AI

Roadmap hasil audit production terbaru tersedia di
[`AUDIT_2026-08-01.md`](AUDIT_2026-08-01.md). Dokumen tersebut menjadi prioritas eksekusi aktif.

Roadmap aktif MrKarirBot saat ini terdiri dari **2 phase utama**. Integrasi WhatsApp Business API dihapus dari roadmap aktif sementara waktu agar fokus pengembangan tetap pada Telegram Bot dan Website Dashboard.

## Phase 1: Telegram Bot Enterprise

Tujuan Phase 1 adalah membuat MrKarirBot aktif dan stabil sebagai asisten karier berbasis Telegram.

Ruang lingkup utama:

- Telegram Bot API.
- Inline keyboard dan callback query.
- Session state dan conversation flow.
- AI Career Assistant.
- AI Chat.
- AI ATS CV Review.
- AI Interview Coach.
- Job search.
- User account foundation.
- Upload CV/resume/portfolio readiness.
- Backend REST API pendukung.
- PostgreSQL, Redis, Alembic migration, dan Docker deployment.

## Phase 2: Website Dashboard

Phase 2 hanya dimulai setelah Phase 1 selesai, aktif, dan terverifikasi.

Ruang lingkup utama:

- Website dashboard berbasis Next.js/React.
- Login/register web.
- Profile management.
- CV Builder.
- Resume Builder.
- Cover Letter Builder.
- Job tracker dashboard.
- AI tools via web.
- Admin dashboard.
- Analytics dan reporting.

## Di Luar Roadmap Aktif

WhatsApp Business API tidak termasuk roadmap aktif saat ini. Modul WhatsApp dapat dipertimbangkan kembali setelah Phase 1 dan Phase 2 selesai serta stabil di production.
